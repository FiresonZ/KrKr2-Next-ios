关于本项目

基于上游 krkr2 重构的独立项目，专注 Apple 平台。

🎮

原生兼容

完全兼容原版 KiriKiri2 游戏脚本，内置高精度 TJS2 解析器，支持 PSB 动画与 Live2D Cubism 扩展。

⚡

零拷贝渲染

ANGLE (Metal) 离屏渲染，经 IOSurface 零拷贝直达 Flutter 纹理，低功耗告别卡顿。

📱

iOS 优先

iOS 为主目标，macOS 作为开发/调试平台。Android / Linux / Windows 已移除。

平台支持

引擎以不同二进制形态接入 Flutter 壳。

平台状态图形后端纹理共享引擎形态
iOS 🚧 主目标 · 开发中 Metal IOSurface 静态库链接进 Runner
macOS ✅ 开发目标 Metal IOSurface dylib 打包进 Frameworks

快速开始

在 macOS 上构建（需要 Xcode、CMake、Ninja、Flutter）。

$ ./build.sh ios release   # 构建 iOS
$ ./build.sh macos debug   # 构建 macOS（开发）
